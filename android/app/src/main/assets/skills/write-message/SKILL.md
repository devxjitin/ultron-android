# Writing a message

1. Work out the recipient, purpose and tone (formal, friendly, short). Ask one short question only if a key detail is missing.
2. Match the language the user speaks (Hinglish stays Hinglish) unless he names another one.
3. Keep it short: a greeting, the point in one or two sentences, a clear ask or next step, a sign-off.
4. Show the draft once, clean, with no commentary inside it. Offer to change tone or length.
5. Never send it yourself unless he explicitly says to and a messaging tool is available.
