# Share live location on WhatsApp

1. Open the person's chat and verify the header (shared).
2. click_on_text "Attach" (paperclip or plus), then "Location", then "Share live location". If WhatsApp or Android asks for location permission, tell the user to allow it on the phone (it may ask for "Allow all the time"); do not tap Allow for them.
3. Pick the time the user said (15 minutes if they gave none), then click_on_text "Send".
4. read_screen: a live location bubble is the newest one. Report it and always say for how long it is shared.

Live location keeps updating until the time ends or the user stops it, so never start it unless the user said "live".
