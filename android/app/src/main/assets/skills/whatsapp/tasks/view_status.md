# View a person's WhatsApp status

1. open_app "WhatsApp", read_screen, press_back to the main tabs if a chat is open, then click_on_text "Updates" (older versions: "Status").
2. click_on_text with the person's name under Recent updates (spelling may differ; several fit: ask which). Not listed: say they have no new status.
3. The status plays full screen. look_at_screen to describe a photo or video and read_screen for caption text. tap_screen_position on the right edge for the next one; press_back to leave.
4. Say honestly what you saw; never guess what a video contains.

Opening a status tells the poster the user viewed it. Do not reply to or react to it unless asked; a reply goes to that person's chat (then use send_message).
