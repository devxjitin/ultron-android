# Send a document on WhatsApp

Follow **Send a found file** (shared) with the kind **document** (PDF, Word, Excel, slides, text). The file name, the folder (for example Download or Documents/Bills) or a date can find it. If several files fit, ask which: sending the wrong document is worse than asking.
