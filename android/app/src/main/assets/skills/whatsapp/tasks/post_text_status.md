# Post a text status

1. open_app "WhatsApp", press_back to the main tabs if a chat is open, then click_on_text "Updates".
2. Tap the pencil icon near the bottom right (click_screen_item from read_screen, or look_at_screen and tap_screen_position on it).
3. type_text the user's words exactly as given, then click_on_text "Send" or the green arrow.
4. read_screen: "My status" shows a recent time. Report "Posted to your status."

## Rules
- Post only what the user asked for, exactly as given.
- Statuses are seen by the user's contacts by default. If the user said "only some people" or "hide from X", open the status privacy setting from the three-dot menu on the Updates tab and ask before changing it.
- Never delete a status unless asked clearly; deleting cannot be undone.
