# Who posted a WhatsApp status

1. open_app "WhatsApp", read_screen. If a chat is open, press_back to the main tabs. Dismiss popups with the least-committal option.
2. click_on_text "Updates" (older versions: "Status"), then read_screen. **Recent updates** lists people with a new status, newest first; **Viewed** lists ones already seen. Channels below are not statuses.
3. Read the names under Recent updates aloud: "Rahul, Mummy and Priya have new statuses." Do not open any: opening a status tells the poster it was viewed. To watch one, use view_status.
4. No one under Recent updates: say there are no new statuses.
