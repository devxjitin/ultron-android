# Post a photo status

1. search_files with the user's words and the kind **image**. One clear result: use it. Several fit: ask which. Never post a file the user did not pick or clearly describe.
2. share_file with its number and app "WhatsApp" and **no phone number**. WhatsApp shows its **Send to** list: click_on_text "Status" (it may read "My status"), then the green Send arrow at the bottom right. read_screen first: the item must be going to Status and not to a chat.
3. Add a caption only if the user gave one (click_on_text "Add a caption").
4. Confirm: read_screen shows "My status" with a recent time. Report "Posted to your status."

Never post a photo of a document, ID or card unless that is exactly what was asked. Statuses are seen by the user's contacts by default.
