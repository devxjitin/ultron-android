# Send an audio file on WhatsApp

Follow **Send a found file** (shared) with the kind **audio**. WhatsApp sends it as an audio file the person can play. Recording a brand-new voice note is not possible from here: if the user asked for that, say so and offer to send a text message or an existing audio file instead.
