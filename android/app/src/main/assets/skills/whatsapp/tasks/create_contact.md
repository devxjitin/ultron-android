# Save a new contact for WhatsApp

1. You need a name and a phone number with country code. Ask for anything missing.
2. Read both back and wait for a yes.
3. Prefer the create_contact tool (Calls connector) with the name and number: it saves straight to the phone's contacts, and WhatsApp picks them up.
4. If create_contact is not in your tool list, open WhatsApp, start a new chat, choose "New contact", fill the name and phone fields with type_text, then tap "Save" and confirm with read_screen.
5. Tell him the contact was saved and that it can take a moment to appear in WhatsApp.
