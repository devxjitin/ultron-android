# WhatsApp status (Android)

## Viewing statuses

1. open_app "WhatsApp", read_screen. If a chat is open, press_back to the main tabs. Dismiss popups with the least-committal option.
2. click_on_text "Updates" (older versions: "Status"). read_screen. **Recent updates** lists people with a new status, newest first; **Viewed** lists ones already seen. Channels below are not statuses.
3. **Who posted?** Read the names under Recent updates aloud ("Rahul, Mummy and Priya have new statuses"). Do not open any yet unless the user asked.
4. **A person's status:** click_on_text with their name (spelling may differ; if several fit, ask). It plays in full screen. look_at_screen to describe a photo or video, and read_screen for caption text. Tap_screen_position on the right edge to go to the next one; press_back to leave. Say honestly what you saw; never guess what a video contains.
5. Opening a status tells the poster the user viewed it. When the user only asked who posted, stop at step 3.

## Posting a status

- **A photo or video from the phone:** search_files to find it (ask which if several fit), then share_file with its number and app "WhatsApp" and no phone number. WhatsApp shows its **Send to** list: click_on_text "Status" (it may read "My status"), then the green Send arrow at the bottom right. Check with read_screen that the item is going to Status and not to a chat.
- **A text status:** open WhatsApp, click_on_text "Updates", then the pencil icon (click_screen_item from read_screen, or look_at_screen and tap_screen_position on the pencil near the bottom right). type_text the user's words, then click_on_text "Send" or the green arrow.
- Add a caption on a photo only if the user gave one (click_on_text "Add a caption").
- Confirm: read_screen shows "My status" with a recent time. Report "Posted to your status."

## Rules
- Post only what the user asked for, exactly as given. Never post a photo of a document, ID or card unless that is exactly what was asked.
- Statuses are seen by the user's contacts by default; if the user said "only some people" or "hide from X", open the status privacy setting from the three-dot menu on the Updates tab and ask before changing it.
- Do not reply to or react to someone's status unless asked; a reply goes to that person's chat.
- Never delete a status unless asked clearly; deleting it cannot be undone.
