# Send the current location on WhatsApp

1. Open the person's chat and verify the header (shared).
2. click_on_text "Attach" (the paperclip; on some versions a plus button), then click_on_text "Location".
3. click_on_text "Send your current location". If WhatsApp or Android asks for location permission, tell the user to allow it on the phone; do not tap Allow for them.
4. read_screen: the location bubble is the newest one in the chat. Report in one sentence.

Send only to the person the user named.
